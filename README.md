# OOD Problem

Private project workspace for the final project on diagnosing OpenClaw / DeepScientist research-agent weaknesses on out-of-domain business and economics research design tasks.

Key files:

- `revised_final_project_openclaw_deepscientist-3.pdf`: course project requirements.
- `Bench_idea.md`: initial benchmark idea discussion.
- `OOD_CausalDesignBench_pipeline_plan.md`: detailed pipeline plan for the proposed benchmark.
- `deepscientist_econ_business_experiment_papers.md`: candidate business/economics experiment paper list.
- `downloads/deepscientist_econ_business_experiment_papers/`: local paper sources used for case construction.
