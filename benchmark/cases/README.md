# Cases Directory

Each benchmark case lives in one subdirectory copied from `C000_template`.

Use anonymous names only:

```text
C001_consumer_credit/
C005_online_ad_measurement/
C008_retail_tax_salience/
```

Do not use original paper titles, author names, exact locations, or unique phrases in case directory names.

Only files named `agent_task_*.md` may be loaded into an agent run.
